# Kindle Capture Studio

PySide6ベースのGUIからKindleアプリを自動操作し、全ページのスクリーンショット取得とPDF化をワンクリックで行うmacOS専用ツールです。進捗表示・ログ記録・セッション再利用を備え、ストレスのない顧客体験を目指しています。

## 主な特徴

- ✅ Kindleウィンドウ自動検出 & プルダウン選択
- ✅ Quartz APIでウィンドウ領域のみを高速キャプチャ
- ✅ OpenCVベースのSSIM判定で終端を自動検知
- ✅ PySide6 GUIで開始/停止・進捗・ログを一元表示
- ✅ セッションごとにPNGとレポート(JSON)を保存し、PDF再生成もワンクリック
- ✅ 出力フォルダ/ページ方向/待機時間/閾値をGUI上で即変更
- ✅ `sessions/` と `logs/` に履歴を自動保管

## 必要環境

- macOS 13以降（Kindleアプリが動作すること）
- Python 3.10 以上
- Kindle for Mac（Mac App Store 版推奨）

## セットアップ

```bash
pip install -r requirements.txt
```

依存ライブラリ（抜粋）:
- PySide6 … GUI
- pyobjc-framework-Quartz … macOSウィンドウキャプチャ
- pyautogui … ページ送りキー送信
- opencv-python / numpy / Pillow … 類似度判定と画像処理

## 使い方

1. Kindleで対象の書籍を開き、最初のページを表示します。
2. このリポジトリで `python kindle_screenshot.py` を実行してGUIを起動します。
3. 「Kindleウィンドウ」プルダウンから対象ウィンドウを選択し、必要に応じて出力フォルダ・閾値・待機時間を調整します。
4. 「開始」を押すと自動でキャプチャ→ページ送り→終端判定→PDF生成まで行います。
5. 完了ダイアログでPDFの保存先を確認できます。`sessions/日付時刻/` にPNGと `session.json` が残るため、失敗時も「PDF再生成」からやり直せます。

## GUI設定項目

| 項目 | 説明 |
| ---- | ---- |
| ページ方向 | 右開き(←) / 左開き(→) を選択 |
| 待機秒 | ページ送り後の待機時間。重い本では長めに設定 |
| 類似度閾値 | SSIMのしきい値。高いほど厳格に同一ページ判定 |
| 終了判定回数 | 同一ページが連続で何回続いたら最終ページとみなすか |
| 比較開始ページ | 誤検出防止のため、何ページ目から比較を有効にするか |
| 出力フォルダ | PDFの保存先。GUIから変更可能 |

## セッションとログ

- `sessions/<timestamp>/` に `page_XXXX.png` と `session.json` を保存。`session.json` には環境設定や経過時間が記録されます。
- `logs/kindle_capture.log` に常に詳細ログを追記。GUIのログビューにもリアルタイム表示されます。

## トラブルシューティング

| 症状 | 対処 |
| ---- | ---- |
| Kindleウィンドウが検出されない | Kindleを起動し最前面に表示後、GUIの「再取得」を押す。macOSの画面収録/操作のアクセシビリティ権限を付与する |
| 同じページで停止する | 「待機秒」を延ばすか「類似度閾値」を下げる（例: 0.90→0.85）|
| 最終ページを通過してしまう | 終了判定回数を増やす（例: 4→6）|
| PDF再生成したい | 「PDF再生成」ボタンを押すと最新セッションのPNGから再度PDFを作成 |

## 自動化ポリシー

- `pyautogui` のフェイルセーフを有効化しており、左上にマウスを移動すると即停止します。
- GUIの「停止」ボタンは安全にループへ停止イベントを送るだけなので、Kindleの状態を壊しません。
- 失敗しても生PNGを保持するため、後処理や再検証が容易です。
