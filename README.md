# Kindle自動スクリーンショットスクリプト

MacBookでKindleアプリを自動操作し、縦書き書籍の全ページをスクリーンショット撮影してPDFにまとめるPythonスクリプトです。

## 機能

- Kindleアプリを自動的にアクティブ化
- 本のタイトルを自動取得
- 全ページを自動的にスクリーンショット撮影
- 最後のページ到達を自動検出
- すべてのスクリーンショットを1つのPDFファイルに結合

## 必要な環境

- macOS
- Python 3.7以上
- Kindleアプリ（Mac App Store版）

## インストール

1. 必要なライブラリをインストール:

```bash
pip install -r requirements.txt
```

2. スクリプトに実行権限を付与（オプション）:

```bash
chmod +x kindle_screenshot.py
```

## 使用方法

1. Kindleアプリを起動し、スクリーンショットを撮影したい本を開きます
2. スクリプトを実行:

```bash
python kindle_screenshot.py
```

3. スクリプトが自動的に以下を実行します:
   - Kindleアプリをアクティブ化
   - 本のタイトルを取得
   - 各ページをスクリーンショット撮影
   - 左矢印キーで次のページへ進む
   - 最後のページに到達したら自動停止
   - すべてのスクリーンショットをPDFに結合

4. 完了後、`{本のタイトル}_screenshots.pdf` というファイルが作成されます

## 注意事項

- Kindleアプリが起動している必要があります
- Kindleアプリのウィンドウが表示されている必要があります
- 縦書き書籍を想定しています（左矢印キーで次ページへ進みます）
- スクリプト実行中は、マウスを画面の左上隅に移動すると中断できます（フェイルセーフ機能）
- スクリプト実行中は、Kindleアプリのウィンドウを操作しないでください

## 設定の変更

スクリプト内の以下の変数を変更することで動作を調整できます:

- `PAGE_WAIT_TIME`: ページ送り後の待機時間（デフォルト: 1.0秒）
- `PDF_QUALITY`: PDF品質（デフォルト: 95）

## トラブルシューティング

### Kindleアプリが見つからない

- Kindleアプリが起動していることを確認してください
- アプリケーション名が「Kindle」であることを確認してください

### スクリーンショットが撮影されない

- Kindleアプリのウィンドウがアクティブになっていることを確認してください
- スクリプト実行中に他のアプリケーションを操作していないことを確認してください

### ページが正しく検出されない

- ページ送り後の待機時間（`PAGE_WAIT_TIME`）を長くしてみてください
- Kindleアプリの読み込み速度が遅い場合、待機時間を調整してください
